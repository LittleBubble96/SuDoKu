## 使用约定

- 后续优先查看和引用本目录；不再通过 Screens_v1～v9 选图。
- 此次仅复制当前版本并统一命名，保留原始像素、尺寸和内容；没有重绘、缩放或切图。
- 不同历史原图的实际分辨率可能不同，切图前仍按具体制作要求核对。
- 原目录作为历史留档保留，不删除历史图、不修改已切散图、预制体或代码。
- 后续页面确认后，在本目录更新该页面和本清单，避免再散落新增版本目录。
