# 蓝白九格应用图标 v1

日期：2026-11-06。用途：小程序头像、应用图标。

## 设计依据

参考项目当前效果图中的首页、经典对局和蜜桃换色示例，主方案沿用经典界面的亮蓝、白色和深蓝数字。保留首页标识的 1、5、9 对角线排列，中心格使用浅蓝色选中态。以蓝色满版背景强化小尺寸下的识别，白色九格主体保持正向、居中，四角留出圆形头像裁切空间。

此版为独立图标设计稿，未添加尚未确定的游戏名称。

## 制作与核验

- 生成方式：内置 image_gen 工具，非 CLI/API 回退。
- 原始生成图由内置工具输出；在项目内保留原图副本。
- 使用 Windows System.Drawing 做尺寸导出和 PNG 编码；未改动生成图的主体、数字、颜色或构图。
- 已读取导出文件，核对实际尺寸、PNG 格式及文件大小。
- 已视觉检查 144 像素方形、圆形裁切和 48 像素预览：数字 1、5、9 可辨识，主要内容未被裁掉。
