# 结算与领奖接入

## 已确认规则

- 玩家填数或使用提示通关后，先保留约 0.65 秒完成波纹，再弹出 `UISettlement`。GM 填题不生成奖励、不累计成绩。
- 普通模式“继续游戏”从当前难度的共享关卡池取下一关，沿用递增、回绕游标。仅在窗口和棋盘就绪后提交取题。
- 每日挑战“继续游戏”返回 `UIHome` 的每日挑战页签，选中原挑战日期。已经完成的日期仍不能重玩。
- “返回主页”始终进入首页页签，包含从每日挑战的结算返回。
- 点击结算礼盒打开 `UIReward`。普通与每日挑战相同：基础奖励 100 金币、1 提示；完整观看激励视频后同时翻倍。
- 正常领取、关闭领奖窗口、未领奖就继续或返回主页，都只发一次基础奖励；双倍领取成功后不再追加基础奖励。
- 通关快照中保存领取标记，奖励余额与标记在同一缓存快照提交。应用在结算或广告中退出，重新启动时补发未领取的基础奖励。
- “挑战好友”调用现有 `GameSDK.SDK.ShareAppMessage`，分享难度、分数和用时，不携带同题挑战跳转协议。

## 计分与配置

新增 `TEngine/Configs/GameConfig/Datas/Settlement.xlsx`，Luban 表名 `settlement.TbSettlement`。每个难度一行，id 为 0～5。

| 难度 | 基础分 | 参考秒数 |
| --- | ---: | ---: |
| 快速 | 100 | 180 |
| 初级 | 200 | 300 |
| 中级 | 400 | 600 |
| 高级 | 600 | 900 |
| 专家 | 800 | 1200 |
| 大师 | 1000 | 1800 |

分数 = 基础分 + 向下取整的速度奖励 − 错误扣分 − 提示扣分，最终向下取整且最低 0。

速度奖励 = 基础分 × speedPercent / 100 × Max(0, 1 − 实际秒数 / 参考秒数)。默认上限 50%。每次错误扣基础分的 5%，每次提示扣 10%，与提示来源无关。最后一步使用提示先计入次数，再冻结分数。笔记、选格、清除不计错误；撤销不会消除已经产生的错误扣分。重开重置本局次数与计时。

`coins` / `tips` 控制两种基础奖励。配置修改后走原有 `TEngine/Luban/转表`。正式启动异步预载此表，检查六档完整性。各难度分别保存 `bestScore`，普通与每日共用该难度纪录；最快用时复用原有统计。

## 代码与预制体

运行时代码以 `Assets/GameScripts/HotFix/GameLogic` 为根：

- `Sudoku/Application/SudokuScoringRules.cs`：配置校验及计分。
- `Sudoku/Core/SudokuSettlementData.cs`：冻结的成绩、原挑战日期、奖励、唯一 ID 和领取倍数。
- `Sudoku/Application/SudokuGameController.cs`：计数、通关结算、领取去重、重启补发、切局自动领取。
- `UI/UIHome/UISettlement.cs`：已有结算节点绑定、数据显示、礼盒、导航、分享、主题和多语言。
- `UI/UIHome/UIReward.cs`：领取入口、广告状态、模板实例及顺序飞行动画。
- `UI/UIHome/RewardTokenItem.cs`：每项图标加载、数量和名称、独立 root 动画。布局占位保持在父级 token，避免 LayoutGroup 与动画冲突。
- `UI/Sudoku/UISudoku.cs`：通关后的结算入口，同一结果只自动弹出一次，异步回调校验窗口版本与结果引用。

复用 `Assets/AssetRaw/UI/UIHome/UISettlement.prefab`、`UIReward.prefab`，保留用户搭建的主体布局。补充了根 CanvasGroup 和遮罩设置、领奖右上角 `CloseBtn/Icon`，修正 `token/root` 内背景、图标、数量与名称的尺寸和位置。运行时复制隐藏 `token` 模板生成金币和提示两个 Widget，缓存重开复用。图标异步加载并在 Widget 销毁时释放。

每项约 0.48 秒从宝箱口飞到奖励栏，接 0.16 秒缩放落位；数量和名称在落位时显示。动画使用独立时间，关闭可取消；领取按钮在展示完成后启用。遮罩、弹窗使用原有 `UIPopupAnimation`。白色 UI 散图、文字和按钮随调色盘变化，金币、礼盒等彩色美术保留原色。

语言表追加 8 条中英文，结算已有文案和通用领取、提示文案复用已有 Key。已通过既有 LanguageGenerateKeyEditor / LanguageGenerateEditor 更新 Key 和现有 GeourceSansCHS 字体资源。
