# 语言下拉框裁剪修复

`UIHome_Setting.prefab` 中语言下拉框的 Item 高 62.2727，但 Content 模板只有 28 高。TMP_Dropdown 根据 Item 与 Content 的相对边距计算实际展开高度，因此两项被误算为 `62.2727 × 2 + (28 − 62.2727) = 90.2727`，第二项遭到 Viewport 裁剪。

已通过 Unity Editor API 修正共用预制体：

- `Center/Layout/GameOther/LanguageItem/dropdown/Template/Viewport/Content`：高改为 78.2727，保留选项高度，并在上下各留 8 像素。
- `Content/Item`：垂直锚点由中间改到顶部，Y 位置改为 -39.13635，匹配上述留白。
- 展开两项的实际高度为 140.5454。保留 Template 的 150 高上限、现有字体、遮罩、样式和语言内容。

首页设置页与局内 UISetting 均引用该共用预制体。无需增加 LayoutGroup 或 ContentSizeFitter；TMP_Dropdown 本身负责选项排列和 Content 高度。

实际 Play 中已检查两种入口、中英文选项、真实 Toggle 点击切换、切换主题、所有选项边界完全位于 Viewport 内，以及标签的 preferredHeight 不超出可用高度。测试结束后已退出 Play，玩家缓存与备份逐字节一致。截图和报告在 `work/language-dropdown`。

`SudokuSettingsValidation.CheckLanguageDropdown` 已加入现有设置 UI 回归，检查真实展开列表，而不只程序赋值给 Dropdown.value。临时 Editor 修复/执行脚本已移出 Assets。
